## 권장 진행 순서

1. `02` 문서의 **하네스 정비(H-1 ~ H-6)** 를 먼저 Codex에 맡긴다. 검증 게이트가 없는 상태에서 기능을 늘리면 회귀를 잡을 수 없다.
2. `01` 문서 마지막의 **결정 필요 항목**을 정한다. (영상 호스팅, 환불 정책, 수강 기간 등)
3. `05` 문서대로 GitHub 준비(H-9)와 자동 루프 구현(H-10)을 Codex와 대화형으로 진행한다.
4. `04` 문서의 카드를 GitHub 이슈로 등록하고 `agent:ready` 라벨을 붙인다. 루프가 PR을 올리면 검토 후 머지하고, 머지하면 루프가 다음 이슈로 넘어간다.

## 기존 문서

- `user_prompt.md`, `user_spec.md`, `프로젝트 구조.txt`: 초기 회원가입/로그인 작업 지시
- `superpowers/`: 강의 카탈로그 기능의 spec/plan
- `frontend/docs/`: 카카오 로그인 spec/plan, 코드 리뷰 보고서
